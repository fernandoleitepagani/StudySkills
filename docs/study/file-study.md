# File Study

Planned for v0.3.0. See [roadmap2.md](../../roadmap2.md).

## What it will do

`file-study` will turn local files into study documents. You supply the sources by attaching them or by giving their names or paths. There is no Canvas connection, no token, and no network access.

It will use the same interview, plan, didactic style, output format rules, partial-format report, and Documents destination as `canvas-study`.

## When to reach for it

- You have lecture slides, PDFs, notes, or readings on disk.
- You do not want to connect a Canvas account.
- You want the same study outputs from manually supplied files.
