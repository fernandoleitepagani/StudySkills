# Concept map template

Use this structure for `concept-map.pptx` and/or `concept-map.pdf`.

## Structure

- Central node: course or topic.
- Main branches: modules or themes.
- Child nodes: key concepts.
- Labeled links: relationships.
- Legend: color or line meaning.
- Source note.

## Rules

- Short node labels.
- One idea per node.
- Avoid crossing lines.
- Keep it readable at A4 or slide size.
- Use navy for structure and amber for emphasis.
- Prefer editable PPTX when the user wants to edit.
- Prefer PDF when the user wants to view or print.

## Source note

List the modules, pages, or files used to build the map.
