# Study skills

A collection of user-invoked skills for studying, learning, and creating.

## v0.2.x

- [canvas-study](./canvas-study/SKILL.md): fetch a Canvas course read-only and generate study documents.
- [lecture-notes](./lecture-notes/SKILL.md): turn lecture material into structured notes.
- [flashcard-forge](./flashcard-forge/SKILL.md): create Anki-ready CSV and Markdown flashcards.
- [explain-back](./explain-back/SKILL.md): explain concepts in layers with the Feynman technique.
- [exam-sim](./exam-sim/SKILL.md): generate timed practice exams and optional review schedules.
- [study-planner](./study-planner/SKILL.md): plan multiple courses around deadlines and weekly hours.
- [note-organizer](./note-organizer/SKILL.md): organize Markdown and Obsidian notes read-only.

## Internal

- [study-core](./study-core/SKILL.md): shared engine for the v0.2 study skills. Model-invoked only.
