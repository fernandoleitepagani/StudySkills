# Study skills

A collection of user-invoked skills for studying, learning, and creating.

## Current

- [canvas-study](./canvas-study/SKILL.md): fetch a Canvas course read-only and generate study documents.

## Planned

- `file-study`: study from local files supplied by attachment, name, or path. See [roadmap2.md](../../roadmap2.md).

All skills are user-invoked. They use the native question UI of the harness, generate only requested files, and save outputs under `~/Documents/StudySkills/`.
