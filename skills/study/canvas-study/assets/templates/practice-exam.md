# Practice exam template

Use this structure for `practice-exam.<format>`.

## Cover

- Course name
- "Practice exam"
- Time limit
- Number of questions
- "StudySkills"

## Instructions

- Time limit
- Number of questions
- Allowed materials
- How to use the answer key

## Questions

Number every question. Mix recall, application, and analysis.

## Answer key

For each question:

- Correct answer
- Short explanation
- Source topic

## Rules

- Match the requested count, format, difficulty, and time limit.
- Do not use keyword-only questions.
- Every answer references a course topic.
