# Summary template

Use this structure when generating `summary.<format>`.

## Cover

- Course name
- "Summary"
- Date
- "StudySkills"

## How to use this summary

One short paragraph. Explain that each topic has a key idea, an example, a common mistake, and a self-check.

## Big picture

- What the course is about
- The main themes
- How the themes connect

## Topic sections

Repeat for each topic.

### Topic name

**Key idea:** one sentence.

**Explanation:** plain-language explanation.

**Key terms:**

| Term | Definition |
| --- | --- |
| | |

**Example or analogy:** one concrete example.

**Common mistake:** one mistake and how to avoid it.

**Check yourself:** one question, with the answer in a short note.

## Formula or reference sheet

Include only if the course needs it.

## Recap

Five things to remember.

## Sources

List the source pages or files used for this summary.
