# Flashcards template

Use this structure for `flashcards.md`. Generate `flashcards.csv` with the columns `front,back,tags`.

## Topic name

Q: One fact per card.

A: Short answer.

## Topic name

Q: Another fact.

A: Short answer.

## Rules

- One fact per card.
- Front is a question or prompt.
- Back is a short answer.
- Tags are lowercase topic names.
- Escape commas and quotes in CSV.
- Match the requested count.
